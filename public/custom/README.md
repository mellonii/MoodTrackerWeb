# Кастомизация оформления

Всё оформление настраивается в этой папке. После любых изменений достаточно
обновить страницу (F5) — пересборка не нужна.

## Структура

```
custom/
├── theme.json       — настройки (цвета, эмоции, фон)
├── README.md        — этот файл
├── background.jpg   — фоновая картинка (имя любое, путь указывается в theme.json)
└── emotions/        — картинки эмоций
    ├── awful.png
    ├── bad.png
    ├── neutral.png
    ├── good.png
    └── great.png
```

## theme.json

Все поля необязательны. Нет файла или поля — используется значение по умолчанию.

- **`background`** — имя файла фоновой картинки (`"background.jpg"`) или `null`.
  Поверх картинки автоматически накладывается полупрозрачная подложка цвета
  фона, чтобы карточки и текст читались.
- **`colors`** — цвета интерфейса, HEX-строки:
  - `bg` — цвет фона страницы
  - `card` — фон карточек
  - `text` / `textMuted` — основной и приглушённый текст
  - `accent` — акцент (обводки, стрелки, активные элементы)
  - `accentStrong` — тёмный акцент (кнопки «+», «Сохранить»)
  - `accentSoft` — мягкая подложка (подсветки, колёсики выбора)
  - `border` — рамки
- **`emotions`** — для каждого настроения (ключи `Awful`, `Bad`, `Neutral`,
  `Good`, `Great` — не переименовывать):
  - `color` — цвет настроения: обводка смайлов, подложка, точки в календаре.
    Точка под днём в календаре — усреднённый цвет всех записей этого дня.
  - `image` — путь к картинке (например `"emotions/awful.png"`). Если файла
    нет или он не загрузился — останется стандартный эмодзи.

## Требования к картинкам

Чтобы всё выглядело адекватно, придерживайся этих правил:

### Эмоции (emotions/*.png)

- **Формат:** PNG с прозрачным фоном (или SVG с таким же содержимым).
- **Пропорции:** квадрат 1:1.
- **Размер:** рекомендуемый 256×256 px, минимум 128×128 px.
- **Стиль:** одинаковый у всех пяти картинок (одна серия/один художник),
  одинаковая «весомость» линий и цветов.
- **Компоновка:** объект по центру, отступ от краёв примерно 10% — картинки
  показываются маленькими кружками в списках и крупными кнопками в выборе.
- **Вес:** до ~200 КБ на файл.
- Картинка может не быть круглой — круглую подложку рисует приложение.

### Фон (background)

- **Формат:** JPG или PNG.
- **Размер:** минимум 1920×1080 (16:9), больше — лучше, показывается с
  `cover` на весь экран.
- **Тона:** светлые и приглушённые. Поверх накладывается полупрозрачная
  подложка цвета `bg`, поэтому тёмный пёстрый фон всё равно «замылится» —
  лучше сразу выбирать нежную картинку.
- **Вес:** до ~2 МБ, иначе страница будет открываться медленно.
