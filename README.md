# Mood Tracker Web

Фронтенд трекера настроения на **Vue 3 + Vite**. Подключается к ASP.NET-бэкенду
(`MoodTracker`), который должен быть запущен на `http://localhost:5000`.

## Запуск

```bash
npm install
npm run dev     # http://localhost:5173
```

Запросы идут через Vite-прокси `/api/* → http://localhost:5000/*`,
поэтому CORS на бэкенде настраивать не нужно (в dev-режиме).

## Что реализовано

- **Сайдбар** слева — переход между разделами (пока активен только трекер, остальные — заглушки, как в макете)
- **«Добавь настроение на сегодня»** — 5 смайлов, каждый со своим цветом; клик создаёт запись или обновляет существующую за выбранный день
- **«Записи в дневнике»** — карточки записей с комментарием за выбранный день; клик по записи — описание + редактирование, «+» — новая запись
- **Календарь** справа — переключение месяцев ← →, клик по дню выбирает день, под числами точки с цветом настроения дня
- **Модалка записи** — просмотр, редактирование (PUT), удаление (DELETE)

## Используемые эндпоинты бэкенда

| Метод | Путь | Назначение | Статус |
|---|---|---|---|
| GET | `/mood` | все записи | ✅ |
| GET | `/mood/{id}` | одна запись | ✅ |
| POST | `/mood` | создать запись (одну) | ✅ |
| PUT | `/mood/{id}` | редактировать запись | ✅ |
| DELETE | `/mood/{id}` | удалить запись по id | ✅ |

Отсутствуют на бэкенде (по твоему списку): массовое создание (POST массива),
удаление по массиву IDs, фильтр записей по датам (сейчас фронт получает всё и
фильтрует по дням на клиенте).
